# Midori `FillMemory` disassembly

The Japanese release `midori-jp-rev0` is the origin reference. All 2 cataloged releases (Japanese) contain exactly one ROM0 `classic` implementation. The RGBDS source preserves the observed countdown strategy and the release maps retain identity, address, variant and code hash without publishing ROM bytes. Candidate/verified status is carried through from the existing release catalog and is not promoted by this match.
