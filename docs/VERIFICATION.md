# Verification

Verification claims should be reproducible and scoped to a specific target.

- **Observed** — directly confirmed from target evidence.
- **Reproduced** — a documented process recreates the expected result.
- **Matched** — the reproduced result satisfies an explicit matching criterion such as exact bytes, hash equality, exact decoded structure, or deterministic comparison.

Record target identity, method, tools, expected result, actual result, and hashes/reports when applicable. Retail or rebuilt playable ROM images must not be committed merely to demonstrate a match.
