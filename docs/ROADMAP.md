# Roadmap

Metadata, architecture conventions, evidence tables, tools, tests, CI, and
collaboration templates are ready.

## Baseline identification

- [ ] verify Rev 0 and Rev A baselines
- [ ] map revision-specific bank and entry-point differences
- [ ] classify text, graphics, maps, scripts, and audio

- [ ] establish a complete address-space map with confidence;
- [ ] identify stable symbols and cross-references;
- [ ] document data and media formats with reproducible examples.

## Reconstruction readiness

- [ ] pin the toolchain;
- [ ] define automated build and hash gates;
- [ ] begin source reconstruction only for evidence-backed ranges.
