# Assembly Reconstruction

This directory contains source reconstructed directly from the verified Pocket Monsters Midori ROM revisions.

The disassembly is incremental. Files are added only when byte ranges have been classified well enough to represent honestly as code or data. The current source is not yet a complete matching build.

Revision-specific source uses explicit conditional guards instead of assuming Rev 0 and Rev A are interchangeable. ROM binaries are never stored here.
